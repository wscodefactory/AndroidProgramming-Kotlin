# Android Programming & Kotlin

[한국어](#한국어) | [English](#english)

## 한국어

대학교 전공수업에서 학습한 **안드로이드 프로그래밍과 코틀린(Kotlin)**의 실습 및 복습 파일을 모아 두는 저장소입니다.

수업 시간에 작성한 실습 코드와 과제를 정리하고, 배운 내용을 다시 연습하면서 학습 과정을 기록합니다.

## 학습 내용

- 코틀린 문법과 프로그래밍 기초 실습
- 안드로이드 앱 개발 실습
- 수업 실습 내용 복습 및 추가 연습

## 폴더 구성

| 폴더 | 내용 |
| --- | --- |
| `Android/` | 안드로이드 프로그래밍 수업 실습 파일을 정리할 공간 |
| `Kotlin/` | 코틀린 수업 실습 코드와 과제 자료 |
| `Kotlin/practice/` | 학습한 내용을 복습하는 날짜별 연습 파일 |
| `test/` | 안드로이드 앱 개발 테스트 프로젝트 |

## 정리 방식

- 수업 실습 파일은 주차 또는 학습 주제에 따라 정리합니다.
- 복습 파일은 실습 내용과 날짜를 기준으로 기록합니다.
- 학습 과정에서 코드를 수정하고 새로운 실습 파일을 추가합니다.

It documents my learning progress through classroom exercises, assignments, and additional practice to reinforce what I have learned.

### Learning Topics

- Kotlin syntax and programming fundamentals
- Android app development
- Review of classroom exercises and additional practice

### Repository Structure

| Directory | Description |
| --- | --- |
| `Android/` | Space for Android programming course exercises |
| `Kotlin/` | Kotlin course exercises and assignment materials |
| `Kotlin/practice/` | Review exercises organized by date |

### Organization

- Classroom exercises are organized by week or topic.
- Review exercises are recorded by content and date.
- Code is updated and new exercises are added as learning progresses.
