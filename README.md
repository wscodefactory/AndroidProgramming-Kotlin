### 🚀 실행 방법

**코틀린 실습**

1. IntelliJ IDEA에서 학습할 프로젝트 폴더(예: `Kotlin/5/week5`)를 엽니다.
2. `src/`에서 확인할 실습 파일을 선택합니다.
3. 해당 파일의 `main()`을 실행하고 콘솔 출력을 확인합니다.

**안드로이드 실습**

1. Android Studio에서 `test/` 폴더를 엽니다.
2. 프로젝트의 Gradle 동기화를 완료합니다.
3. 에뮬레이터 또는 연결한 안드로이드 기기를 선택해 앱을 실행합니다.

> 프로젝트 설정과 실행 환경은 실습마다 다를 수 있습니다. 코틀린 예제는 실행하려는 파일의 `main()` 함수를 선택해 실행합니다.

### 🎓 About This Repository

This repository contains **Android programming and Kotlin exercises, assignments, and review materials** from university coursework.

I revisit classroom examples and assignments, reimplement what I have learned, and explore variations to deepen my understanding. This repository documents that learning process, one exercise at a time.

| 📚 Classroom Exercises | ✍️ Assignments | 🔁 Review & Practice |
| :---: | :---: | :---: |
| Put course concepts into code | Keep weekly code and course materials | Revisit and adapt examples to reinforce learning |

### 🏫 Course Overview

This course introduces mobile application development for Android using Kotlin, the officially recommended language for Android development. It starts with setting up the development environment in Android Studio, then covers UI development and the core technologies used to build real-world web and mobile services.

### 🎯 Course Objectives

| Area | Objective |
| --- | --- |
| 📱 Platform | Understand mobile platform architecture |
| 🛠️ Development Foundations | Become proficient in Kotlin and the Android development environment |
| 🎨 Interface | Implement user-centered UI/UX |
| 🗄️ Data | Manage local and remote data |

The course uses this Korean-language textbook, which covers Kotlin syntax and mobile app development through 19 hands-on examples.

### 🌱 Learning Roadmap

> **Understand → Implement → Check the output → Review → Apply to app development**

| Stage | Topics | Examples in this repository |
| --- | --- | --- |
| 01 · Fundamentals | Conditionals, loops, lists, and functions | Grade calculations and loop exercises |
| 02 · Functions | Lambdas, higher-order functions, and function references | Passing operations as functions |
| 03 · Comparing Approaches | Callbacks and higher-order functions | Different ways to implement the same functionality |
| 04 · Android Basics | Activities, XML layouts, and resources | An Android test project |
| 05 · Review | Reimplementing course concepts | Additional exercises organized by date |

### 🚀 Running the Exercises

**Kotlin:** Open an individual project folder, such as `Kotlin/5/week5`, in IntelliJ IDEA. Select an exercise under `src/`, run its `main()` function, and inspect the console output.

**Android:** Open `test/` in Android Studio, complete Gradle sync, and run the app on an emulator or a connected Android device.

> Project settings and environment requirements may vary between exercises. To run a Kotlin example, select the `main()` function in the relevant file.
